# Radar — енергетика, паливо, логістика, промисловість

Стрічка галузевих новин з автоматичним збором, перекладом заголовків і фільтрами.
Працює безкоштовно на GitHub: **Actions** збирає новини кожні 10 хв, **Pages** показує сторінку.

## Що вміє

- Вкладки за джерелами: **Усі · Світ · Україна · Мої джерела · Важливе**.
- Фільтр за темами: нафта й пальне, газ, електроенергія, ВДЕ, логістика, промисловість. Можна обрати кілька тем.
- Заголовки іноземних видань перекладаються українською. Оригінал видно при наведенні мишки.
- Однакові новини з різних джерел склеюються, а сторінка показує «+N джерел».
- «Важливо» ставиться, якщо подію дали 2+ джерела або в заголовку є маркери терміновості.
- Смужка зліва позначає новини, яких ви ще не бачили. Є також «Сховати прочитані», ✕ для приховування окремої новини і пошук.
- Сторінка сама перевіряє оновлення щохвилини, без F5.
- Внизу сторінки є стан джерел: які працюють, які впали і чому.

## Розгортання (≈10 хвилин)

1. Створіть на GitHub новий **публічний** репозиторій, наприклад `radar`.
   Публічний потрібен, бо Pages безкоштовні лише для публічних репозиторіїв, а запуски Actions тоді не обмежені за хвилинами.
2. Завантажте в нього всі файли з цього архіву: **Add file → Upload files**.
   Тека `.github` прихована, тому перевірте, що вона теж завантажилась.
3. **Settings → Actions → General → Workflow permissions** → оберіть **Read and write permissions** → Save.
4. **Actions** → workflow «Оновлення стрічки» → **Run workflow**. За 1–2 хв у репозиторії з'являться `data/news.json` та `data/status.json`.
5. **Settings → Pages** → Source: **Deploy from a branch**, Branch: `main`, тека `/ (root)` → Save.
6. За хвилину сайт буде доступний за адресою `https://<ваш-логін>.github.io/radar/`.

## Як додати або прибрати джерело

Усе налаштовується у файлі `config/sources.yaml`, код чіпати не потрібно.
Редагувати файл можна прямо на GitHub: олівець → Commit. Після цього збір запуститься сам.

```yaml
  - name: Назва видання
    url: https://site.ua/rss       # адреса RSS-стрічки
    tab: mine                      # world | ukraine | mine
    lang: uk                       # uk — без перекладу; en, de, pl… — з перекладом
    filter: true                   # брати лише новини, що потрапили в теми (для загальних видань)
```

**Якщо в сайту немає RSS**, використовуйте Google News:
`https://news.google.com/rss/search?q=site:назва-сайту.ua+when:2d&hl=uk&gl=UA&ceid=UA:uk`.
Так само можна зробити стрічку за будь-яким пошуковим запитом.

Теми та їхні ключові слова налаштовуються в тому ж файлі (розділ `topics`).
Слово із `*` на кінці працює як корінь: `нафт*` знайде і «нафта», і «нафтовий».

## Обмеження, про які варто знати

- **Затримка.** Збір запускається раз на 10 хв, але GitHub у години навантаження відкладає запуски на 5–20 хв.
  До цього додається затримка самих RSS та Google News. Реалістично новина з'являється у стрічці за 10–40 хв після публікації.
- **Вимкнення розкладу.** Якщо в репозиторії 60 днів не було ручних змін, GitHub може вимкнути розклад.
  Тоді в Actions з'явиться кнопка «Enable workflow».
- **Переклад** іде через безкоштовний Google Translate (бібліотека deep-translator). Якщо він тимчасово недоступний,
  заголовок лишається мовою оригіналу, а наступний прогін перекладе його.
- **«Важливе»** визначається евристикою: кількість джерел плюс ключові слова. Оригінальний Radar натомість дивиться,
  чи видання винесло новину на головну. Це точніше, але вимагає окремого парсера під кожен сайт.
- Деякі RSS-адреси в стартовому списку я не міг перевірити. Після першого запуску відкрийте «Стан джерел» внизу сторінки:
  ті, що з ✗, виправте або вимкніть (`enabled: false`).

## Локальний запуск

```bash
pip install -r requirements.txt
python scripts/fetch.py
python -m http.server 8000      # і відкрити http://localhost:8000
```
