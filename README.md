# MediaRadar — енергетика, паливо, логістика, промисловість

Стрічка галузевих новин з ~70 видань: збирається автоматично, заголовки перекладаються українською, новини розкладаються по вкладках.
Працює безкоштовно на GitHub: **Actions** збирає новини кожні 10 хв, **Pages** показує сторінку.

## Вкладки

| Вкладка | Що там |
|---|---|
| **Усі новини Україна** | усе, що стосується України: з українських видань і з іноземних, якщо згадано Україну, Київ або українські компанії |
| **Важливе** | новини про Україну, які дали 2+ видання одночасно або з маркерами терміновості |
| **В тренді Google** | пошукові тренди Google в Україні за вашими темами (зараз або протягом тижня) і топ Google News для України |
| **Європа** | ділові новини про Європу за вашими темами; новини, що стосуються й України, позначені міткою «Україна» |
| **Світ** | світові новини, включно з європейськими, без тих, що стосуються України |

Одна новина може бути в кількох вкладках. Стовпчики над стрічкою показують кількість новин щогодини за добу.
Червоне на стовпчику — важливі новини. Натисніть стовпчик, щоб побачити лише цю годину.

На телефоні вкладки переїжджають униз екрана, як у застосунку.

## Налаштування — `config/sources.yaml`

- **Джерела** (`feeds`). Якщо в джерела вказано `rss`, береться RSS. Якщо RSS немає або він не працює, збирач сам бере заголовки з Google News за доменом (`site`).
  Такі джерела опитуються раз на 30 хв, щоб Google не блокував запити.
- **Що вважати українським** (`ukraine`), **європейським** (`europe`), **іноземним** (`foreign`) — списки ключових слів.
- **Теми** (`topics`) і **виключення** (`exclude`, наприклад футбольний «Шахтар»).
- **Важливе** (`important`).

Слово із `*` — корінь (`нафт*` знайде «нафта», «нафтовий»), без `*` — ціле слово.
Теми визначаються за українським перекладом заголовка, тож німецькі чи польські видання фільтруються так само.

Додати видання:
```yaml
  - { name: Назва, site: site.ua, rss: "https://site.ua/rss", region: ua, lang: uk, filter: true }
```
`region`: ua | intl | eu · `lang`: мова заголовків (не uk → переклад) · `filter: true` — лише новини за вашими темами.

## Розгортання з нуля

1. Публічний репозиторій на GitHub, завантажити всі файли (папки `.github`, `config`, `scripts` мають бути видні).
2. Settings → Actions → General → Workflow permissions → **Read and write permissions**.
3. Actions → «Оновлення стрічки» → **Run workflow**.
4. Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Обмеження

- Затримка від публікації до появи у стрічці — 10–40 хв, для джерел через Google News — до години.
- Переклад через безкоштовний Google Translate. Якщо він недоступний, заголовок лишається мовою оригіналу до наступного прогону.
- «Важливе» визначається евристикою, а не тим, що видання винесло новину на головну.
- Сам Google Discover недоступний: він персональний і не має відкритих даних. Вкладка «В тренді Google» — найближча заміна.
